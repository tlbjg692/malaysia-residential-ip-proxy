## 住宅 IP、原生 IP、机房 IP 差在哪

朝暮数据在自己的 FAQ 里给了两个定义。原生 IP 指“IP 地址的运营商所在国家和服务器的地理位置一致”；住宅 IP 是“互联网服务提供商 ISP 分配给家庭或个人用户的 IP 地址”，因为来自真实家庭网络，在某些场景下更容易被认成真实用户。

这两条不是一回事。一台机器可以既有原生 IP 又不是住宅 IP：IP 段注册在马来西亚、机房也在马来西亚，但整段属于数据中心段，平台查一下 ASN 就知道。朝暮自己的产品页把这个差别直接标在价格上——X 区原生 IP 49 元/月起（1 核 1GB、10GB 系统盘、不限带宽、750GB 月流量），i 区住宅 IP 147 元/月起。同一座城市、同一家商家，差价接近三倍，差的就是 IP 段性质。

所以看到“马来西亚 VPS 49 元起”就以为捡到住宅 IP，是把两个标签看成了一个。机房 IP 的特点是速度快、稳定、便宜，适合建站和跑在线业务；住宅 IP 贵，贵在平台侧的身份判定。

## 怎么用：链式代理加指纹浏览器

SOCKS5 节点在大陆不能直连，前面要先挂一个能出境的节点。V2rayN 的做法是新建一个订阅分组，在分组里添加 SOCKS 配置，填 IP、端口、用户名、密码，再给这个分组设“前置代理”，选一个香港或其他地区的机场节点。教程演示中刷新后查 IP，落地显示马来西亚吉隆坡，IP 类型显示家庭宽带 IP，ASN 是当地住宅 ISP。这是那期视频里的演示结果，属于第三方单次读数。

手机端 Nekobox 有两种配法：对整个分组设前置代理，或者对单个节点用“链式代理”，依次添加机场节点和马来西亚住宅 IP 节点。顺序有讲究，第一个节点先走，最后一个才是落地 IP。iOS 小火箭在“代理通过”里选前置线路，全局路由改成代理。

指纹浏览器要配合本地的 V2ray 或 Clash。系统代理选“自动配置系统代理”，路由规则绕过大陆。ADS Power 有个容易漏的开关：账户 → 各类设置 → 本地设置 → 网络连接设置，打开之后浏览器才走系统代理。不打开就得让代理客户端开 TUN 模式，而 TUN 模式下流量不能分流。新建环境时选 SOCKS5，填主机、端口、账号密码，点“检查代理”验证。

## 纯净度和欺诈值，该不该当验收标准

2025 年 10 月那期教程里，作者用 P0 查落地 IP，显示纯净度 17%、欺诈值 0，他把这当作质量不错的证据。朝暮数据的 FAQ 则直接否认这套指标：“某些网站提供的 IP 欺诈值检测并没有评分依据，IP 地址也没有纯净、干净、新老的说法。实际上，TikTok 等公司有自己的 IP 地址库和检测手段。”

两个说法对着干。一边是第三方演示的即时读数，一边是商家的官方口径，都不是平台方的规则说明。可操作的结论是：把这类分数当参考，别当验收标准。真正影响账号存活的是 IP 段性质、这个 IP 之前被多少人用过、设备指纹和行为是否一致。想验证，就按教程作者自己说的，先买最短周期的小套餐跑几天，别一上来买年付。
